# Business Process Monitor

Учебное веб-приложение для просмотра состояния заранее определённых бизнес-процессов.

Автор: Михайленко Елизавета Сергеевна, РИМ-160960.

## Текущий этап

Лабораторная работа №4: структура репозитория, backlog и семантическая главная HTML-страница с минимальными стилями. React-приложение и программная логика MVP на этом этапе не реализованы.

## Открыть страницу

Откройте `tempPage/index.html` в современном браузере. Установка Node.js и запуск сборки для этого HTML-файла не требуются.

Кнопки «Подробнее» пока отключены. Подробные страницы и обновление состояния относятся к этапу ЛР №6.

## Границы MVP

- Список процессов и подробная карточка.
- Этапы, статус, процент выполнения и ответственный.
- Изменение статуса и прогресса, последовательный переход между этапами.
- Сохранение состояния в localStorage в том же браузере для того же адреса сайта.

В первую версию не входят создание процессов, изменение структуры этапов, авторизация, серверная база данных и внешние интеграции. Данные и имена сотрудников являются условными учебными примерами.

## Технологии

Текущий этап: HTML5, минимальный CSS, Git. Планируемый MVP: React + Vite, JavaScript, CSS, React Router и localStorage.

## Структура

```text
tempPage/       HTML-страница ЛР №4 и стили
src/components/ будущие компоненты React
src/pages/      будущие страницы приложения
src/data/       будущие демонстрационные данные
src/services/   будущие функции проверки и хранения состояния
src/styles/     будущие стили приложения
public/         будущие статические файлы
docs/           накопительная документация проекта
```
