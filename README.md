# Business Process Monitor

Учебное веб-приложение для просмотра состояния заранее определённых бизнес-процессов.

Автор: Михайленко Елизавета Сергеевна, РИМ-160960.

## Текущий этап

Лабораторная работа №5: стилевое оформление и адаптивная главная страница. Сохранены семантические элементы и данные ЛР №4; добавлены молочно-коричневая палитра, карточки, метки статусов и адаптивная сетка. Программная логика MVP относится к ЛР №6.

## Открыть страницу

Откройте `tempPage/index.html` в современном браузере. Установка Node.js и запуск сборки для этого HTML-файла не требуются.

Кнопки «Подробнее» пока отключены. Подробные страницы и обновление состояния относятся к этапу ЛР №6.

## Границы MVP

- Список процессов и подробная карточка.
- Этапы, статус, процент выполнения и ответственный.
- Изменение статуса и прогресса, последовательный переход между этапами.
- Сохранение состояния в localStorage в том же браузере для того же адреса сайта.

В первую версию не входят создание процессов, изменение структуры этапов, авторизация, серверная база данных и внешние интеграции. Данные и имена сотрудников являются условными учебными примерами.

## Технологии

Текущий этап: HTML5, CSS3, CSS Grid, Flexbox, media queries, Git. Планируемый MVP: React + Vite, JavaScript, CSS, React Router и localStorage.

## Оформление и адаптивность (ЛР №5)

- Палитра и основные размеры взяты из согласованного прототипа Figma.
- Все правила находятся в `tempPage/styles.css`; inline-стили и `!important` не используются.
- CSS Grid задаёт сетку: три столбца при ширине больше 1120 px, два при 721–1120 px, один при ширине до 720 px.
- Flexbox используется в шапке и карточках. Высота карточек растёт вместе с текстом.
- Заголовки h1/h2/h3, header, nav, main, section, article, footer и native progress сохранены. Статус выделен в отдельный dl внутри каждой карточки; остальные пары dt/dd сгруппированы для оформления.
- Ссылка перехода к содержимому видна при клавиатурном фокусе. Статусы различаются текстом и цветом; декоративные SVG имеют пустой alt.
- Результаты выполненных проверок указаны в `docs/lab5-validation.md`.
