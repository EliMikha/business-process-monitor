# ЛР №5: оформление и адаптивная главная страница

Дата проверки: 23.10.2026.

## Изменения

- Использованы палитра и размеры согласованного прототипа Figma: молочный фон, светлые карточки и коричневые акценты.
- CSS находится в отдельном `tempPage/styles.css`. Основные элементы имеют осмысленные классы.
- CSS Grid задаёт сетку карточек; Flexbox используется в шапке и внутри карточек.
- Media queries переключают сетку с трёх столбцов на два при ширине до 1120 px и на один при ширине до 720 px.
- Сохранены header, nav, main, section, article, footer, иерархия h1/h2/h3, пары dt/dd и native progress. Статус вынесен в отдельный dl внутри каждой карточки для соответствия прототипу. Изменены группировка и классы, значения процессов сохранены.
- SVG-индикаторы статусов из Figma сохранены в `tempPage/assets/`; временных URL в коде нет. Каждый SVG отображается в своём статусе с исходными размерами 5×5 px.
- Кнопки «Подробнее» сохраняют disabled: логика и остальные страницы относятся к ЛР №6.

## Выполненная проверка

Проверка выполнена автоматически в Microsoft Edge 155.0.4283.62 (headless) при изменении размеров окна. Это проверка браузерного отображения, без запуска на физических мобильных устройствах.

| Ширина окна, px | Столбцов | Горизонтальная прокрутка |
| --- | --- | --- |
| 320 | 1 | отсутствует |
| 390 | 1 | отсутствует |
| 720 | 1 | отсутствует |
| 721 | 2 | отсутствует |
| 768 | 2 | отсутствует |
| 1024 | 2 | отсутствует |
| 1120 | 2 | отсутствует |
| 1121 | 3 | отсутствует |
| 1440 | 3 | отсутствует |

Дополнительно проверены:

- иерархия заголовков, уникальность ID и существование целей якорных ссылок;
- сохранение названий, этапов, статусов, ответственных и процентов выполнения из ЛР №4;
- подключение CSS, отсутствие ошибок синтаксиса, inline-стилей и !important;
- загрузка SVG, размеры и отсутствие выхода основных элементов за границы окна;
- переход к содержимому через Tab и Enter и работа ссылки к списку процессов;
- отсутствие ошибок JavaScript и HTTP-ошибок загрузки ресурсов.

Изображения для визуальной проверки сохранены отдельно в папке ЛР5/Предпросмотр: 390, 768 и 1440 px.
