# Состояние ЛР №4

Подготовлены backlog DOCX, исходные данные backlog JSON, CSV для YouGile, README, .gitignore, структура папок и главная HTML-страница с минимальным CSS. Локальный Git-репозиторий инициализирован с веткой main.

Отправка кода в GitHub, история коммитов и импорт задач в YouGile требуют подключения соответствующего аккаунта и выполнения действий в сервисах. На момент подготовки файлов эти действия не подтверждены. Автор и email для Git-коммитов должны быть заданы владельцем проекта; фиктивная учётная запись не используется.

Окончательная готовность ЛР №4 определяется заданием: Word-backlog + доступная доска + GitHub со страницей и коммитами. Подготовка файлов сама по себе не заменяет публикацию и импорт.
